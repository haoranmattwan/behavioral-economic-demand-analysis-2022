# Contributing

Reproducibility reports, documentation corrections, and focused improvements to the analysis code are welcome.

## Before opening a change

1. Search existing issues to avoid duplicate work.
2. Describe the analysis, software version, and operating system involved.
3. For numerical discrepancies, report the expected and observed estimates and provide the smallest reproducible example possible.
4. Do not commit unpublished data, credentials, local file paths, or licensed article files.

## Pull requests

Keep each pull request limited to one clear purpose. Explain why the change is needed, identify the affected analysis, and note how it was verified. If a change affects a numerical result, update the relevant rendered output and state whether it changes any conclusion in the published article.

By contributing code, you agree that it may be distributed under the repository's MIT License. Contributions involving data or publication materials require separate confirmation of reuse rights.
